## 1. 改訂の基本方針

現稿には、フェルミ加速、輸送、Hillas 条件、Peters cycle、核種別スペクトル、移行モデル、Heitler–Matthews モデル、ミューオン問題まで、すでに重要な材料があります。これらを最初から書き直すのではなく、次の順序が読み取れる構成に整理してください。

**観測された特徴 → 加速と伝播が作るスペクトル → 銀河系内・銀河系外成分の接続 → 組成・異方性・他の観測による制約 → 空気シャワーからのエネルギー推定 → TALE-SD の位置づけ**。

second knee を、最初から iron knee、銀河系内宇宙線の完全な終端、銀河系内外成分の等寄与点と同義にしないでください。異なる検出器による差を、新しい起源成分の証拠やミューオン問題の発見と直結させないでください。一方、定数較正や陽子・鉄の二仮定だけを理由に、エネルギー依存の応答差を除外しないでください。

本書で「追加」とする項目がローカル原稿にすでにある場合は、既存の節へ統合してください。重複する文章や図を増やさないでください。

### E03：質量組成の用語と定義を整える

**場所**：`subsec:cosmic_ray_composition`、第2章の重ね合わせモデル、表と図の説明。

参照した原稿はすでに `\ln A の平均` と書いており、「平均対数質量」という語は導入していません。この点は維持してください。

最初の定義を次の内容にそろえてください。

```tex
質量数を \(A\)、同じエネルギーにおける核種 \(i\) の割合を
\(f_i\) とすると、質量組成を表す量の一つとして
\begin{equation}
  \langle\ln A\rangle=\sum_i f_i\ln A_i,
  \qquad \sum_i f_i=1
\end{equation}
を用いる。これは質量数の自然対数を核種の割合で平均した量であり、
平均質量数の対数 \(\ln\langle A\rangle\) とは一般に異なる。
```

後は記号を使い、「平均対数質量」「対数平均質量」などの新しい日本語名に置き換えません。原論文の英語題名にある `Mean Logarithmic Mass` は、書誌情報なので改変しないでください。表の「平均質量」が実際に指すものが `\langle\ln A\rangle` なら、記号へ置き換えてください。

既存の `fig:tale_lna` は推定された組成を示す図として残します。その前に F02 の測定された `\langle X_{\max}\rangle` を示し、測定量と模型を介した組成推定を区別してください。

### E05：加速の説明から、到達エネルギーと伝播へつなぐ

**場所**：フェルミ加速の節、`eq:source_propagation_spectrum`。旧約174–390行。

1次・2次加速の違い、テスト粒子近似、`s=(r+2)/(r-1)`、源スペクトルと観測スペクトルの違いは残してください。散乱角の積分や同じ式の代入を繰り返す部分は、本文では要点を残し、詳細を付録へ移せます。

「上流と下流のプラズマが衝撃波面に向かって流れ込む」は修正します。衝撃波静止系では上流は衝撃波へ流入し、下流は衝撃波から流れ去ります。`u_1>u_2` と、異なるプラズマ静止系間を粒子が往復することを説明してください。

`D(\mathcal R)` を導入する前にリジディティを定義してください。`J\propto Q\tau_{esc}` は、定常状態、対象核種、損失を省いた近似であると明示します。源の加速限界と銀河からの逃走を、同じ「カットオフ」として一括しないでください。

### E06：リジディティの式と単位を修正する

**場所**：`subsec:rigidity_larmor`、`subsec:peters_cycle` のエネルギー・リジディティの式、銀河系外源の最大エネルギー。旧約407–612行など。

`\mathcal R=pc/(Ze)` と定義する場合、エネルギーとの関係は `E\simeq Ze\mathcal R` です。`E\simeq Z\mathcal R` と書くなら、`E[eV]=Z\mathcal R[V]` という単位付き数値の関係であることを明記しなければなりません。Peters cycle の式と broken-power-law の無次元比の分母を含めて整合させてください。

現稿のラーモア半径はガウス単位系で導出されています。SI とガウス単位系の `c` の有無を混在させる一括置換をしないでください。数値式が成立する単位を明示します。

### E19：重ね合わせモデルと実際の組成推定を分ける

**場所**：「重ね合わせモデルと質量組成」。旧約1008–1100行。

純電磁モデルからの模式的な `-X_0\ln A` の導出は、その仮定を明記して残せます。しかし、現稿のように模型の差を加法的な `C(E)` のみへまとめると、質量に対する応答係数の差を表現できません。

実解析の説明は、例えば

```tex
\langle X_{\max}\rangle(E)
\simeq \langle X_{\max}\rangle_p(E)-F(E)\langle\ln A\rangle(E)
```

のように、陽子の予測と質量に対する係数 `F(E)` をともにハドロン模型に依存する量として定義してください。この形の適用範囲と出典は R04 で確認します。`F=X_0` を普遍的な定数として置かないでください。

エロンゲーションレートには `D_{10}` を用い、拡散係数 `D` と区別します。上式を用いるなら、必要に応じて `F'(E)` に由来する項も含めます。測定された `X_max` と、推定した核種割合の別を常に明確にしてください。

### E25：章末にエネルギー較正の節を新設する

**場所**：`subsec:shower_front` の後、`\backmatter` の前。新規 `sec:energy_calibration`。

次の順序で説明してください。

**(a) 指標とエネルギー換算を分けます。** `S(r)`、光密度、縦発達は観測量であり、エネルギーへの写像とその較正は別です。

**(b) Auger の二段階を説明します。** CIC は天頂角による信号の減衰を基準角へ補正する手法です。絶対尺度そのものではありません。その後の実測による `E=A(S/S_0)^B` の較正で、規格化と傾きが求められます。SD433 は SD750 を介して FD 尺度へ接続されます。図 F03 を配置します。[S01]

**(c) MC lookup と定数較正を説明します。** `E_rec=C F_MC(S_600,\theta)` の定数 `C` を定めても、MC が与える傾き・曲率は残ります。較正範囲内でもエネルギー依存の差が残る可能性があります。ここでは方法の比較を行い、TALE-SD の未確認の版の係数を挿入しません。

**(d) ミューオンの効果を最小限の式で示します。** 電磁成分を正しく記述できているという仮定の下で、

\[
 h(E)=S_{data}/S_{MC}=1+f_\mu(E)\{r_\mu(E)-1\},
\]

と書けます。`f_mu` は MC の全信号中のミューオン信号の割合、`r_mu` は実測とMCのミューオン信号比です。`S_MC\propto E^\alpha`、基準 `E_*` での定数較正を仮定すれば、残る差は概ね

\[
 E_{rec}/E\simeq [h(E)/h(E_*)]^{1/\alpha}
\]

となります。この式は説明用の近似で、TALE-SD で測った割合や較正関数ではありません。実際には組成、天頂角、距離、電磁成分の模型差も関係します。

**(e) スペクトルへの写像を説明します。** 分解能を省いた単純な変換では `J_rec(E_rec)=J(E)dE/dE_rec` です。定数のエネルギー倍率でも曲がったスペクトルを同じ表示エネルギーで比較すればフラックス比はエネルギーに依存し得ます。したがって、比の変化だけで非線形性を証明しないでください。一方、定数較正だけから非線形性がないと結論してもいけません。

検出効率とエネルギー分解能の扱いを短く述べます。応答を用いる式を示す場合は、真のエネルギー、再構成エネルギー、露出、条件付き確率の定義と単位を添えます。新しい unfolding を実施する指示ではありません。

**避ける結論**：「CIC はミューオン問題を消す」「FD 由来尺度だから全て模型非依存」「Hybrid の平均差が小さいので形状も正しい」「陽子・鉄の結果が近いのでハドロン模型の系統誤差は小さい」。

Codexは既存文献の読解、提示済みの出典への対応付け、指定URLのファイル取得、図の抽出、LaTeX編集、ビルドを担当します。新しい論文の探索、文献間の判断、未確認の物理的結論、図番号・再利用条件の解決はChatGPTへ渡してください。単なる別のCodexサブエージェントへの割当てをChatGPTへの調査依頼と呼ばないでください。

調査待ちの間は、E01–E08など独立に確定している編集を継続します。根拠が返っていない部分を補完したり、調査依頼を作成しただけで完了としたりしないでください。

## 9. 検証と完了条件

現行 `Makefile` の既定ターゲットはPDFで、LuaLaTeX/latexmkを使います。まず `make pdf` を実行してください。閲覧のために `make open` を自動実行する必要はありません。`clean` や `distclean` を習慣的に先行実行しないでください。

現行設定には `latexmk -f` が含まれるため、PDFの存在だけでは成功と判断できません。終了状態とログを確認し、未定義引用、未定義参照、重複ラベル、欠落図、数式・Unicodeのエラーを解消してください。新たな依存関係の導入は原則不要です。既存環境で実行できない場合は具体的な不足を記録し、ビルド済みと報告しません。

PDFでは、目次、節の順序、表の改ページ、図の文字、キャプションと本文の対応、引用番号、数式のはみ出しを確認します。追加・移動したページは必ず視覚的に確認してください。ラベルと引用キーの検査、差分の読み直しは、ビルドと別に行います。

確認は変更に比例させます。一度通った全体検査を理由なく何度も繰り返さず、新しい変更が影響する箇所を再確認してください。原稿の編集のためだけに汎用テストフレームワークを新設しないでください。

完了時に `docs/revision/edit_report.md` へ以下を記載します。

1. E01–E25それぞれについて、反映先と実施内容を示します。すでに満たしていた項目はそのように記します。
2. 移動・短縮した導出の所在を示します。
3. 追加文献・図と出典確認を示します。
4. ビルドコマンド、結果、紙面確認を示します。
5. 未解消の調査事項がある場合は、本文へ入れなかった内容と理由を特定します。

最終応答は、主要変更、検証結果、残る事実上の制約を日本語で報告してください。追加作業の申し出で終わらず、成果物の場所を明記します。
